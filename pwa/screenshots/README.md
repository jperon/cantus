# Screenshots PWA

Ce dossier contient les screenshots pour l'installation PWA.

## Fichiers requis

- `mobile-1.png` (390x844) - Vue principale mobile
- `mobile-2.png` (390x844) - Menu navigation mobile  
- `desktop-1.png` (1280x720) - Interface desktop

## Instructions

1. Faites des captures d'écran de l'application
2. Redimensionnez aux tailles spécifiées
3. Placez-les dans ce dossier
4. Relancez `npm run build`

Les screenshots améliorent l'UI d'installation PWA sur mobile.
